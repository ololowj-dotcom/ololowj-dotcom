## Открытый проект

**[svcwatch](https://github.com/ololowj-dotcom/svcwatch)** - сторож для Linux-серверов: следит за systemd-сервисами,
Docker-контейнерами, процессами, HTTP и TCP и пишет в Telegram, когда что-то сломалось (с traceback), и когда всё
починилось. Настройка за две минуты (`svcwatch setup`), правила на конкретные сервисы, очередь недоставленных
уведомлений, тесты и CI на Python 3.9-3.13.
